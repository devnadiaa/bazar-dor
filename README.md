# 🛒 বাজার দর | Bazar Dor

### 📌 Project Overview

**বাজার দর (Bazar Dor)** is a modern, responsive web application that helps users explore the daily prices of essential products in Bangladesh. Users can browse products by category, compare prices, track price changes, and access personalized features through authentication.

## 🛠️ Technologies Used

* **Next.js** — Building the user interface
* **App Router** — Page navigation and routing
* **Tailwind CSS** — Styling and responsive design
* **TypeScript** — Type-safe development
* **Better Auth** — User authentication and session management
* **React Hot Toast** — Interactive notifications
* **REST API** — Fetching product prices and category data

## ✨ Key Features

1. **Daily Product Prices** — Explore the latest available prices of essential products.
2. **Category-Based Browsing** — Browse products by categories such as rice and other daily necessities.
3. **Product Details** — View individual product information, current prices, and price changes.
4. **Price Change Indicators** — Identify whether product prices have increased, decreased, or remained unchanged.
5. **Price Sorting** — Sort products by default order, lowest price, or highest price.
6. **User Authentication** — Sign in and sign up securely using Better Auth.
7. **Social Authentication** — Access the application through supported social login providers.
8. **Profile Management** — View and update user profile information.
9. **Protected Routes** — Restrict access to designated pages based on authentication status.
10. **Responsive Design** — Enjoy a consistent experience across desktop, tablet, and mobile devices.
11. **Loading Skeletons** — Display loading placeholders while content is being fetched.
12. **Custom 404 Page** — Show a dedicated page when a requested route does not exist.
13. **Interactive Notifications** — Display feedback for important user actions.
14. **API Integration** — Load product and category information dynamically from the API.
15. **User-Friendly Navigation** — Navigate between pages and product categories easily.

## 🎯 Project Goal

The goal of Bazar Dor is to make essential product prices easier to explore and compare through a simple, accessible, and user-friendly web experience.
